# Changelog

All notable changes to the public edition of OwnSay AAC are documented here.

## 1.0.0 — 2026-09-02

- Initial history-free open-source release.
- Includes two clearly fictional sample profiles and editable local profiles.
- Provides deterministic offline AAC across five routine-aware boards.
- Keeps the protected core stable and speech explicitly user-activated.
- Adds optional, bounded on-device candidate ranking through WebLLM.
- Includes validated backup/restore, local draft recovery, PWA support, accessibility checks, and browser acceptance tests.
- Adds public-source privacy/secret gates and fail-closed welcome-sprite import validation.
