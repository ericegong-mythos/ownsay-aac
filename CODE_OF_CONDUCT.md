# Code of conduct

OwnSay welcomes contributors with different communication styles, disabilities, professions, cultures, and levels of technical experience.

Be respectful, specific, and patient. Critique work rather than people. Do not use demeaning language, disclose private information, or treat a communicator's support needs as a spectacle. Accessibility feedback and first-person lived experience deserve serious consideration without making any individual responsible for educating the whole community.

Maintainers may edit or remove harmful content and restrict participation when necessary. Report urgent conduct or privacy concerns privately through the repository's GitHub Security Advisory channel.
